## 2. Як рахувалася симуляція

| Поле | Значення |
| --- | --- |
| Інструмент | Скрипт Monte Carlo (5000 прогонів, фіксований seed 42) |
| Прогонів | 5000 |
| Що тягнеться випадково | Фактична `points_done` одного з моїх двох спринтів (`8` або `5`) |
| Як рахується дата прогнозу | Останній день спринта: для «Весь перший реліз» `2026-11-06 + (P − 1) × 14` днів; для залишку `2026-11-20 + P × 14` днів |

```python
import random, math

def simulate(vels, target, runs=5000, seed=42):
    rng = random.Random(seed)
    res = []
    for _ in range(runs):
        rem, sp = target, 0
        while rem > 0:
            rem -= rng.choice(vels)
            sp += 1
        res.append(sp)
    res.sort()
    p50 = res[math.ceil(0.50 * runs) - 1]
    p85 = res[math.ceil(0.85 * runs) - 1]
    return p50, p85
```

Що я з цим роблю: Якщо тримати строк у 7 спринтів (14 тижнів), ріжемо з `REL-1` обидві `could`-історії (`S-05` = 5 SP і `S-15` = 8 SP, разом −13 SP), що повертає реліз у 7-спринтову межу навіть при поточній швидкості.
