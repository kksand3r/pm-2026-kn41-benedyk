## 1. Definition of Workflow

| Колонка | Картка потрапляє сюди, коли | Картка виходить звідси, коли |
| --- | --- | --- |
| Backlog | Сформульовано робочий крок на 1–2 дні по найближчих роботах курсу (ЛР5, ЛР6, ЛР7) | Картка розбита до зрозумілого результату й має критерій завершення |
| Ready | Зрозумілий результат картки, немає зовнішніх блокерів, розмір до 1–2 днів | Є вільний слот у `In progress` (не перевищено WIP-ліміт) і виконавець бере задачу в роботу |
| In progress | Зафіксовано дату старту роботи над карткою | Артефакт або розділ створено і його можна відкрити / перевірити валідатором |
| Review | Результат готовий до самоперевірки, звірки з умовою задачі та прогону `validate.py` | Усі зауваження виправлено, файл відповідає схемі та закомічено в репозиторій |
| Done | Картка пройшла перевірку без помилок і зафіксована дата завершення | — (фінальний стан на дошці) |
